# Desafio 2 — Modelo dimensional no Power BI

Segundo desafio de modelagem dimensional do Módulo 5, usando a planilha Financial Sample.

## Modelo

O arquivo do Power BI organiza os dados em `F_Vendas` e dimensões de produtos, detalhes dos produtos, descontos, detalhes e calendário. A consulta `Financials_origem` fica oculta como cópia da tabela original. O calendário foi criado em DAX.

O modelo foi organizado a partir das orientações do [enunciado do desafio](f11bb55a-ab79-4e73-8fd7-e35bb72d751d.docx). A captura mostra as tabelas e seus relacionamentos na exibição Modelo.
